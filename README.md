# 🎓 Student Result Prediction using Machine Learning

## 📌 Project Overview
This project predicts student academic performance using Machine Learning techniques by analyzing demographic and academic features.

## 📊 Dataset
- Dataset Name: StudentsPerformance.csv
- Source: Kaggle
- Features:
  - Gender
  - Race/Ethnicity
  - Parental Level of Education
  - Lunch
  - Test Preparation Course
  - Math Score
  - Reading Score
  - Writing Score
